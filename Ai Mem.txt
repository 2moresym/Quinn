Project: Quinn, a local-only GNOME AI command assistant.

ARCHITECTURE
- GNOME Shell extension is GJS/JS only.
- Rust quinn-daemon owns Needle inference and tool execution.
- UI talks to daemon over session D-Bus.
- D-Bus name: org.quinn.Assistant
- Object path: /org/quinn/Assistant
- Interface: org.quinn.Assistant
- Ask(query: string) -> (response: string, tool_calls: JSON string)
- Signal: ToolExecuted(name, args, result)
- Property: Ready: bool

MODEL
- Use Needle v2, NOT the old v1-only loading plan.
- Current needle-rs release verified: v0.2.1.
- Rust API: needle_infer::v2_engine::V2Engine.
- Model file: Cactus-Compute/needle2/needle2.cact (~13.7 MB).
- Default local path: ~/.local/share/quinn/weights/needle2.cact
- Override with QUINN_MODEL.
- Model runtime is pure Rust; no Python runtime dependency after model download.

IMPORTANT DESIGN RULES
- Local-only: no cloud/API calls.
- No Python at runtime.
- Keep GNOME extension thin; Rust owns inference/tools.
- Needle v2 normally maps one utterance to one call; split multi-command input before inference.
- Never blindly execute low-confidence tool calls.
- Do not turn Quinn into a general chat app unless a second local model is explicitly added.
